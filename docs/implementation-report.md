# MVP実装報告

## 1. 完成した機能

- 共通名簿: 複数行貼り付け、空行・前後空白除去、追加、編集、削除、除外、全員復帰
- 同姓同名警告と内部IDによる個別管理
- 撮影用の架空データ30人と明示表示
- 席替え: 1〜10行・1〜10列、無効席、固定席、前方指定、隣接させない複数ペア
- グループ分け: 均等人数、固定グループ、同じグループにしない複数ペア
- 順番決め: 除外反映、先頭・最後固定、連番
- Web Crypto乱数とFisher–Yatesシャッフル
- 条件を満たせない場合の最良案と具体的な警告
- 席・グループ・順番のドラッグ操作による手動修正
- Undo/Redo（最大50操作）
- 席替えA4横、グループ・順番A4縦の印刷・PDF保存
- 直近2回の席履歴を使った類似配置の抑制
- 任意の暗号化履歴保存、読込、ロック、削除
- 入力後のページ離脱警告
- PC、タブレット、スマートフォン向けレスポンシブ表示

## 2. 使用技術

- Vite、React、TypeScript、CSS Modules
- Vitest、Testing Library、jsdom
- dnd-kit
- Web Crypto API（乱数、PBKDF2、AES-GCM）
- IndexedDB（暗号文だけを任意保存）

## 3. 外部送信されないことの確認

- 本番コードで`fetch`、XHR、Beacon、WebSocket、EventSourceを使用していない。
- 外部URL、外部フォント、CDN、解析タグ、SNSリンクを使用していない。
- CSPで本番の`connect-src 'none'`を設定している。
- `npm run check:privacy`でソースを静的検査できる。
- ブラウザでダミーデータを用いた操作中にコンソールエラーがないことを確認した。

## 7. 残っている制約

- 印刷結果はブラウザごとの差があるため、公開先と実際に使用する端末で最終プレビューが必要。
- 暗号化履歴は同じブラウザ・同じ公開元でのみ利用できる。
- パスフレーズを忘れた履歴は復元できない。
- 条件が数学的に不可能な場合は、最大5,000試行後の最良案になる。
- 端末やブラウザ拡張機能自体が侵害された場合は保護できない。
