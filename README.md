# 生徒名かんたん割り当て

教員がブラウザ内で、生徒名を席・グループ・順番へ割り当てる無料の静的Webアプリです。バックエンド、ログイン、外部APIは使用しません。

## 機能

- 席替え: 無効席、固定席、前方指定、隣接させない組み合わせ、直近2回との差を考慮
- グループ分け: 均等な人数、固定グループ、同じグループにしない組み合わせ
- 順番決め: 先頭・最後固定、ランダムな順番
- 共通: 除外、重複名警告、ダミー30人、Undo/Redo、ドラッグ操作、印刷・PDF保存
- 任意: 名簿と直近2回の席履歴を、パスフレーズで暗号化して端末内へ保存

## 起動

Node.js 20.19以降（または22.12以降）とnpmが必要です。

```bash
npm install
npm run dev
```

開発サーバーが表示するローカルURLをブラウザで開きます。

## テストと確認

```bash
npm test
npm run check:privacy
npm run build
```

本番ファイルは`dist/`に生成されます。

## 公開

1. `npm run build`を実行します。
2. `dist/`の内容を任意の静的ホスティングへ配置します。
3. HTTPSを有効にします。
4. `public/_headers`形式に対応しない公開先では、同等のCSP・セキュリティヘッダーを公開先の設定へ移します。
5. ダミーデータだけを使い、PC・Chromebook・タブレット・スマートフォンと印刷プレビューを確認します。

### GitHub Pages

このリポジトリには`.github/workflows/deploy-pages.yml`が含まれています。`main`ブランチへpushすると、次を順番に実行し、すべて成功した場合だけGitHub Pagesへ公開します。

1. 依存パッケージの固定インストール
2. 自動テスト
3. プライバシー境界の検査
4. 本番ビルド
5. `dist/`のPages公開

初回だけ、GitHubリポジトリの「Settings → Pages → Build and deployment」でSourceを「GitHub Actions」に設定してください。GitHub Pagesでは`public/_headers`がレスポンスヘッダーとして適用されないため、外部通信の禁止はHTML内のCSPでも実施しています。

## データとプライバシー

- 入力した名前・条件・結果を外部へ送信しません。
- 外部フォント、CDN、アクセス解析、広告、SNSリンクを使用しません。
- 通常のデータはメモリ内だけに置かれ、再読み込みで消えます。
- 任意の履歴保存を有効にした場合だけ、名簿と直近2回の席履歴をAES-GCMで暗号化してIndexedDBへ保存します。
- パスフレーズと復号鍵は保存しません。パスフレーズを忘れた場合は復元できません。
- 共有端末では履歴保存を有効にせず、利用後に全データを削除してください。
- 静的サイトを表示する通常の通信と、ホスティング側の一般的なアクセスログは発生し得ますが、入力内容はリクエストへ含まれません。

実在する個人情報を使った開発・動作テストは行わないでください。

## 基本操作

1. 1行につき1人の名前を貼り付け、「名簿へ追加」を押します。
2. 席替え、グループ分け、順番決めのタブを選びます。
3. 条件を設定し、「自動割り当て」を押します。
4. 必要に応じて名前をドラッグして結果を修正します。
5. タイトルと日付を入力し、「印刷・PDF保存」を押します。
6. 席替え結果を次回の比較対象にする場合は「この配置を履歴へ登録」を押します。

## 既知の制約

- ブラウザ標準の離脱確認は、ブラウザによって表示方法が異なり、任意の文言は指定できません。
- 暗号化履歴は同じブラウザ・同じ公開元でだけ利用できます。ブラウザデータ削除や端末交換では失われます。
- アプリを開いて履歴を復号した状態で第三者が端末を操作することや、端末・ブラウザ拡張機能自体の侵害までは防げません。
- 複雑な条件では完全解が存在しない場合があります。その場合は通常条件の違反が最も少ない案を表示します。
- ドラッグ後は条件違反を許可し、警告を表示します。
